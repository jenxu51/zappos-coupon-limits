## Why a Zappos promo code may not work

A failed code does not always mean the code is fake. Zappos promotions can be limited by product, brand, account, email address, date, or order status.

These are the most common reasons a code is rejected.

### The item belongs to an excluded brand

The current 15% promotion excludes many popular names, including Nike, HOKA, Birkenstock, UGG, VEJA, Tory Burch, Steve Madden, Osprey, Oofos, and others. If you are buying a pair from one of those brands, the code may fail even when the promotion is still active.

This is especially relevant for shoppers searching for running shoes. Nike, HOKA, and several other performance brands appear frequently in Zappos’ sale and product listings, but they may not qualify for a general coupon.

### The cart contains a gift card

The official terms exclude gift cards and e-gift cards from the 15% offer. A shopper may be able to buy regular merchandise and a gift card in the same general shopping session, but the discount should not be expected to reduce the gift card price.

### The order is already discounted in a way the code cannot combine with

Some Zappos listings show a sale price and an additional promotional message. Other items may only qualify for one discount. The checkout system decides whether the offers can be combined.

For example, a product may already be 30% off its list price but still be excluded from a percentage code. The visible markdown and the coupon are separate offers, so compare the final price instead of assuming that the largest-looking discount applies.

### The code is tied to a particular account

The official 15% terms state that the code is limited to one qualifying order per Zappos account. A code copied from another shopper’s email may not be transferable or may already have been used.

### The promotion has expired

Zappos runs short promotional events that can disappear quickly. For example, the site previously displayed a 20% offer using code `FALL20`, but the published product pages stated that the promotion ended at 11:59 p.m. ET on September 29, 2026. That code should not be presented as a current offer on October 6.

This is why old coupon lists can be misleading. They may correctly report that a code existed, but that does not mean it remains valid now.
